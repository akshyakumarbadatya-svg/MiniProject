Multiplication Table Generator
A simple and beginner-friendly Multiplication Table Generator built using HTML, CSS, and JavaScript.

🚀 Features
Generate multiplication tables from 1 to 10
Clean and responsive user interface
Simple bio section
Beginner-friendly code structure
Built with pure HTML, CSS, and JavaScript
📸 Preview
Enter a number and click the Generate Table button to display its multiplication table.

Example:

5 × 1 = 5 5 × 2 = 10 5 × 3 = 15 ... 5 × 10 = 50
